# Brand

**Name:** Tuskline. The CLI is `tl` and the server binary is `tuskline`. The name avoids the PostgreSQL trademarks and the Slonik mascot. Describing compatibility ("for PostgreSQL") is fair use. Before launch, run trademark searches (UKIPO, EUIPO, USPTO; classes 9 and 42) and check domains and package names.

**Mark:** Tusk Arc. It is an original tusk-and-line motif: an arc for the tusk, a line, and a node hinting at data and clusters. There is no elephant or Slonik reference. The wordmark is Inter SemiBold lowercase, set slightly tight and outlined in the SVGs, so it has no font dependency.

## Files (`brand/`)

| File | Use |
|---|---|
| `svg/tusk-arc-icon-{dark,light}.svg` | App icon: rounded-square tile (dark is an Ink tile; light is an Accent tile on Paper) |
| `svg/tusk-arc-lockup-{dark,light}.svg` | Icon plus wordmark, for the README, site and about screen |
| `svg/tusk-arc-favicon-{dark,light}.svg` | Simplified tusk and dot for 16–48 px |
| `png/` | Renders: icon 16/32/64/256/1024, favicon 16/32/48, lockup 64 h/256 h |
| `favicon.ico` | Multi-size favicon |

Use the dark variants on dark backgrounds and the light variants on light backgrounds. Do not recolour, stretch, outline or add effects. Keep clear space of at least the node's diameter around the mark.

## Colours

Ink `#0E1116`, Paper `#FAFAF9`, Accent `#3E63DD`, Accent light `#7B96FF`, Border `#2A303A`. The environment colours (`#E5484D`, `#F5A524`, `#30A46C`, `#8B8D98`) belong to the UI, not to the brand. See [design.md](design.md).

## Voice

Calm, precise and British English. Name problems in words, not just in red. Never overclaim: say what was measured and how.
